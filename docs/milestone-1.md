# Milestone 1 

By the end of the year our team will have built an alpha version of Bubbles in which a user can:

Scan a QR code to join a Bubble created by the system admin, invite other members to that Bubble using a QR code, and leave that Bubble at will.

Additionally, our team will put in work to make the Location API from Smith Micro, as well as any endpoints for the database provider and server application so that the app can have basic functionality, as well as preparing the ground for future changes.

We have 4 main areas to complete in order to make that a reality:

1. Ina - Frontend
2. Sam - Database Schema
3. Syd - Assisting Frontend and Database Schema Work
4. Tim - Location API

The frontend work will involve bringing our UI mockup to life using React Native. Only the Bubble main screen, the QR code generator for users to invite other users, and the leave Bubbles parts of the UI will need to be created.

The database schema will involve taking the current ER diagram and creating working databases in either a local or cloud database provider, and providing endpoints for the team and app to access.

Assisting the Frontend and Database Schema work will involve helping those working on those areas when needed. Since we only have 3 main areas, a floating position is needed.
